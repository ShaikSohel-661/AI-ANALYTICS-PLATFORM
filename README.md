# AI Analytics Platform

## Project Overview

AI Analytics Platform is a web application that allows users to upload datasets in CSV or Excel format and analyze them using Artificial Intelligence.

The platform automatically explores the uploaded dataset, generates summaries, creates interactive visualizations, and allows users to ask questions about their data using natural language.

Instead of manually writing code to analyze datasets, users can simply upload their files and receive meaningful insights generated by AI.

## Features

- Upload CSV and Excel files
- Display dataset preview
- Generate dataset summary
- Detect missing values and basic statistics
- Create interactive charts and graphs
- Ask questions about the uploaded data
- AI-generated insights and explanations

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
- Google Gemini API
- OpenPyXL
